# Экспедиция в СССР: наука и искусство

Интерактивный учебный сайт для подготовки учеников 3–6 классов к олимпиаде «Наше наследие» 2026–2027.

Версия содержит два полных маршрута: «Константин Эдуардович Циолковский» и «Московские высотки». В каждом маршруте есть девять учебных экранов, мини-туры после каждой тройки экранов, карточки без подсказок и итоговая олимпиадная проверка. Остальные четыре маршрута пока не наполнены.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Проект использует относительный базовый путь и готов к GitHub Pages.
